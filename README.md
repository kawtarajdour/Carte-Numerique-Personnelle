# Carte-Numerique-Personnelle
Ce projet est une carte personnelle développée en HTML et CSS. Il présente mes informations personnelles, mes compétences et des liens vers mes profils professionnels (GitHub, LinkedIn, email). Le projet a pour objectif de pratiquer le développement front-end et la création d’une interface web simple et responsive.

# Contenu :
- CartePersonnelle.html : structure de la page
- style.css : design et mise en forme
- photo.jpeg : image de la carte réalisée
